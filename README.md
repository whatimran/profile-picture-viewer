# Profile Picture Viewer

A simple Chrome extension that lets you view full-size Facebook profile pictures.

## How to Install

1. Unzip this folder.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** (top-right toggle).
4. Click **Load unpacked**.
5. Select the unzipped `profile-picture-viewer` folder.

## How to Use

You have **two ways** to open the full-size picture:

### Method 1 – Toolbar Button (new)
1. Open any Facebook profile page.
2. Click the extension icon in the Chrome toolbar.
3. The full-size photo opens in a new tab.

### Method 2 – Right-click
1. Open any Facebook profile page.
2. Right-click anywhere on the page.
3. Click **“Unlock full size profile picture”**.


## Notes
- Works on Facebook and Messenger profile pages.
- Facebook changes its UI occasionally, so the selector may need updating in the future.
- This extension only extracts images that are already visible on the page.
